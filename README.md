# Student Performance Analysis

An Excel dashboard and analysis exploring how student study habits, attendance, learning preferences, educational technology use, discussion participation, and self-reported stress relate to academic outcomes.

## Project file

- `Student Performance Analysis by Priyank.xlsx` — Excel workbook containing the dashboard, analysis and source dataset.

## Dataset

The workbook includes **10,000 student records** and 15 fields, including:

- Demographics: student ID, age and gender
- Study patterns: weekly study hours, online courses completed and discussion participation
- Learning preferences and educational technology use
- Assignment completion, exam score and attendance rate
- Self-reported stress, social media time, sleep and final grade

## Questions explored

The workbook’s analysis includes comparisons of:

- Final grades by gender
- Study-hour bands and final grades
- Exam scores by preferred learning style
- Self-reported stress levels and final grades
- Educational technology use and discussion participation
- Attendance bands and final grades
- Discussion participation and stress levels

## Summary metrics

The workbook reports these overall averages:

| Metric | Average |
| --- | ---: |
| Assignment completion rate | 74.92% |
| Attendance rate | 75.09% |
| Exam score | 70.19% |

## Tools and methods

- Microsoft Excel
- Pivot tables and charts for summarizing and comparing categories
- Data checks and grouped comparisons documented in the workbook’s Analysis sheet

## How to view

Download the `.xlsx` file and open it in Microsoft Excel. Start with the **Dashboard** sheet, then see **Analysis** for supporting summaries and **Student Performance Dataset** for the records.

## Notes

These summaries describe patterns in the workbook’s dataset. They do not establish that any one factor causes a change in student performance. The workbook does not identify a source or collection method for the dataset; add that information here if you have it.
